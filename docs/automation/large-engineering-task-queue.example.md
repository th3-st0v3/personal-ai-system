# PASI Large Engineering Task Queue

Use this as an optional seed for the future live task inbox. Each entry should be a substantial engineering objective, not a tiny edit.

## Queue order

### 01 — Computer-Use Control Plane
Build reliable end-to-end controlled computer operation: browser/ChatGPT, VS Code, terminal/processes, GitHub, web research, state synchronization, response detection, browser/runtime recovery, and persistent operation state.

### 02 — Unattended Task Execution
Enable large objectives to be decomposed, continued, resumed, verified, and progressed without repeated human prompting.

### 03 — Verification + Self-Repair
Build the test/diagnose/repair/retest loop so AI-generated changes require concrete evidence before acceptance.

### 04 — Persistent Project Memory
Persist architecture, requirements, decisions, current work, failures, limitations, and completed milestones so context can be recovered without repeatedly pasting it into prompts.

### 05 — Multi-AI Orchestration
Add provider-neutral routing and context transfer across ChatGPT, Claude, and future specialized/user-created models.

### 06 — Developer Tool Integration
Make VS Code, terminal, filesystem, GitHub, and testing first-class computer-use surfaces.

### 07 — Research + Evidence System
Build trustworthy web/documentation/GitHub research retrieval, provenance, and engineering evidence collection.

### 08 — Higher-Level Personal AI System
Build the broader user-facing system on top of the control plane instead of creating a second automation stack.

### 09 — Task-Specific Models
Replace general-model calls with smaller specialized models where evidence shows they are beneficial.

### 10 — Engineering Knowledge Layer
Build the engineering learning/research/tooling layer across computing and engineering domains.
