# Project Continuation Rules

One project remains active until verified complete.

- Initial prompt establishes project context once.
- Subsequent normal turns use a compact `Continue working...` prompt in the same valid ChatGPT conversation.
- The full project brief is not repeated unless continuity is lost, the conversation changes, the project changes materially, required state is missing, or recovery requires reconstruction.
- Do not accept planning-only or explanation-only output when implementation remains.
- Do not mark the project task complete until deterministic/integration verification supports the acceptance criteria.
- Commit and promote verified increments, then continue with the next substantial task in the project roadmap.
- Preserve all existing security, authorization, approval, authentication, human-control, path, network, and verification boundaries.
