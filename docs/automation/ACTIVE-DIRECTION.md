# Active Automation Direction

PASI unattended runs should prioritize difficult, implementation-heavy engineering projects.

Current priority: Computer-Use Control Plane.

The runner should not default to read-only inspections, tiny cosmetic/documentation edits, or trading-information tasks. A successful engineering task should implement a meaningful capability or defect fix and verify it with reproducible tests/evidence.

Preserve all authentication, authorization, network, path, approval, human-control, and verification boundaries.
